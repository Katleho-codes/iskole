# Demo Script (90 seconds)

1. **Introduction (10s)** - Problem statement: Access to higher education in South Africa
2. **Onboarding (15s)** - Sign up with email verification (demo account pre-verified)
3. **Profile & Marks (15s)** - Build profile and enter subject marks for APS calculation
4. **Match & Discover (20s)** - AI-powered course matching with explanations
5. **Funding & Apply (15s)** - Compare funding options and apply
6. **Success Path (15s)** - Study plan, calendar, and ongoing support

*All features demonstrated use sample data.*
